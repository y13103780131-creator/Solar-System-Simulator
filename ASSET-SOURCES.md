## Source references to verify against exact files

- Celestia Content: <https://github.com/CelestiaProject/CelestiaContent> — the repository states that data-file licensing is documented in its README or per-file `.license` records; filenames alone do not establish permission.
- Solar System Scope textures: <https://www.solarsystemscope.com/textures/> — provider states CC BY 4.0 for its pack and describes fictional fill in unmapped areas. Verify that each bundled file is actually from this pack, preserve attribution, and indicate changes.
- NASA imagery and usage guidelines: <https://www.nasa.gov/nasa-brand-center/images-and-media/> — check any third-party credit embedded in individual media.
- USGS/IAU planetary nomenclature: <https://planetarynames.wr.usgs.gov/> — source for names/coordinates, not blanket permission for unrelated image files.
- Wikimedia Commons: <https://commons.wikimedia.org/> — identify the exact file page and license before relying on a generic author citation.
