# 太阳系漫游模拟器

交互式太阳系探索程序，支持太阳、八大行星、冥王星、主要卫星和部分小天体的三维浏览与独立观察。包含中英文界面、地点简介、模拟时间、图层和截图功能。

## Windows 桌面版

完整下载仓库内容后，双击 `太阳系漫游模拟器.exe`。请保留 `resources`、`太阳系漫游模拟器.exe.config` 和 WebView2 DLL。运行需要 64 位 Windows、Microsoft Edge WebView2 Runtime、.NET Framework 4.7.2 或更高版本及支持 WebGL 的显卡。

详细操作见 [使用说明](使用说明.txt)，素材来源及权利声明见 [素材与项目说明](素材与项目说明.md)。轨道、大小和部分纹理经过示意或艺术化处理，并非精密实时星历。

## 发布状态与版权

当前为私有开发版本。默认 BGM 由程序使用 Web Audio API 实时合成，不包含第三方游戏音乐文件。程序允许用户选择本地音乐；用户需自行确认其来源和使用授权。行星与卫星纹理、Three.js 和其他外部素材的来源与许可仍需逐项核查；第三方素材权利归各自原权利人所有。

缓存与用户截图不包含在仓库中，程序运行时自动生成。
