# 太阳系漫游模拟器 | Solar System Wander Simulator

在浏览器技术构建的 Windows 桌面程序中，探索太阳、八大行星、冥王星、卫星、矮行星、小行星带、柯伊伯带与深空探测器。可自由旋转和缩放视角，进入天体独立观察，查看地貌标签与介绍，并调节时间、光照和画面。

## 主要功能

- 太阳系全景与天体独立观察，支持鼠标、触控和键盘操作。
- 行星、主要卫星、矮行星、彗星、探测器及轨道浏览。
- 时间倍率、光照、曝光、颜色、图层和地点标签控制。
- 中英文界面、沉浸 HUD、原创程序合成音乐与操作音效。
- 支持导入用户本地音乐；其来源和使用授权由用户自行确认。

天体大小、距离和轨道为便于交互的示意模型，部分遥远天体贴图为艺术化重建，不代表精密实时星历或实测地貌。

## 运行要求

- Windows 10/11 64 位
- Microsoft Edge WebView2 Runtime
- .NET Framework 4.7.2 或更高版本
- 支持 WebGL 的显卡

首次启动若系统尚未启用音频，点击窗口即可开始播放原创合成氛围音乐。操作步骤见 [使用说明](使用说明.txt)。素材来源、许可证及版权信息见 [素材与项目说明](素材与项目说明.md)。
